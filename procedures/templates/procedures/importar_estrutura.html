Importação em Massa - Estrutura Completa

Como usar:
  1. Baixe o template Excel clicando no botão abaixo
  2. Preencha as abas seguindo as instruções:
    • Perfis: Código e nome dos perfis de treinamento
    • Grupos: Grupos dentro de cada perfil
    • Subgrupos: Subgrupos dentro dos grupos
    • Procedimentos: Vincule procedimentos existentes aos subgrupos
    • Colaboradores: Associe colaboradores cadastrados aos perfis
  3. Salve o arquivo mantendo o formato .xlsx
  4. Faça upload usando o formulário abaixo

Importante: Procedimentos e Colaboradores devem estar previamente cadastrados no sistema. Use os códigos e matrículas exatos para vinculação.

Proteção contra Duplicatas

O sistema identifica automaticamente registros já existentes:

  • Perfis: Se o código já existe, os dados serão atualizados
  • Grupos: Identifica por Perfil + Nome do Grupo (atualiza se existir)
  • Subgrupos: Identifica por Grupo + Nome do Subgrupo (atualiza se existir)
  • Procedimentos: Não duplica vínculos já existentes
  • Colaboradores: Não duplica associações já existentes

Você pode reimportar o mesmo arquivo sem criar duplicatas! O sistema irá informar quantos registros foram criados vs. atualizados.

Dicas para uma importação bem-sucedida
  • Códigos únicos: Cada perfil deve ter um código único
  • Nomes exatos: Ao vincular grupos e subgrupos, use os nomes exatamente como cadastrados
  • Ordem de importação: O sistema processa na ordem: Perfis → Grupos → Subgrupos → Procedimentos → Colaboradores
  • Validação prévia: Certifique-se de que procedimentos e colaboradores existem antes de importar
  • Matrículas: Use apenas números nas matrículas (ex: 141, não 141.0)
  • Backup: Mantenha uma cópia do arquivo Excel para referência futura
  • Demandas automáticas: Ao associar colaboradores, o sistema criará automaticamente as demandas de treinamento
Soluções para Erros Comuns

Causa: O código do procedimento na planilha não existe no sistema.
Solução:
  1. Verifique se o procedimento está cadastrado em Procedimentos
  2. Confira se o código está digitado exatamente igual (letras maiúsculas/minúsculas, pontos, etc.)
  3. Se o procedimento não existir, cadastre-o primeiro antes de importar

Causa: O sistema não encontrou o subgrupo especificado.
Solução:
  1. Verifique se o nome do Grupo e Subgrupo estão corretos
  2. Certifique-se de que o Grupo pertence ao Perfil correto
  3. Confira espaços extras ou caracteres especiais nos nomes
  4. A ordem importa: Subgrupo deve estar vinculado ao Grupo correto

Causa: A matrícula informada não existe no cadastro de colaboradores.
Solução:
  1. Verifique se o colaborador está cadastrado em RH → Colaboradores
  2. Confirme se a matrícula está correta (sem .0, sem espaços)
  3. Cadastre o colaborador primeiro se ele não existir
  4. Use apenas números na coluna Matrícula
