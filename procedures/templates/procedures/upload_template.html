Como Adicionar Placeholders ao Seu PDF?
Opção 1: Adobe Acrobat Reader/Pro
  1. Abra o PDF no Adobe Acrobat
  2. Vá para Ferramentas → Editar PDF
  3. Clique no ícone de texto
  4. Adicione o placeholder (ex: {{titulo}})
  5. Salve o arquivo
Opção 2: LibreOffice/Microsoft Word
  1. Abra o arquivo original (Word, LibreOffice)
  2. Adicione os placeholders no documento
  3. Formate-os com fontes/estilos (eles aparecerão no PDF)
  4. Exporte como PDF
  5. Envie para o sistema
Opção 3: Ferramentas Online

Use ferramentas gratuitas como:

  • PDF.io - Editor PDF online
  • SmallPDF - Edição de PDF
  • PDFEscape - Adicionar texto em PDFs
Placeholders Disponíveis

Você pode usar estes placeholders no seu PDF:

  • {{titulo}} - Título do Treinamento
  • {{facilitador}} - Facilitador/Fornecedor
  • {{data}} - Data
  • {{local}} - Local
  • {{empresa}} - Empresa

Dica: Use nomes descritivos entre chaves duplas. Exemplo: {{titulo_treinamento}}, {{data_sessao}}

Como Funciona

1. Upload do PDF: Você envia um PDF que serve como base para suas listas de presença.

2. Detecção de Placeholders: O sistema detecta placeholders como {{titulo}}, {{data}}, etc.

3. Mapeamento: Você mapeia cada placeholder para um campo de dados (título do treinamento, data, facilitador, etc).
