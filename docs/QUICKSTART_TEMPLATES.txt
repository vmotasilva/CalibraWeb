📍 ACESSO RÁPIDO
═══════════════════════════════════════════════════════════════════════════════

  1. Vá até "Listas de Presença"  (Procedimentos → Listas de Presença)
  
  2. Clique no botão "Templates"  (novo, em azul)
  
  3. Abre /procedures/templates-presenca/
  
  4. Gerencio seus templates!


🎯 O QUE VOCÊ CONSEGUE FAZER
═══════════════════════════════════════════════════════════════════════════════

  ✅ Criar novo template com nome + descrição
  
  ✅ Upload de arquivo Excel (.xlsx)
  
  ✅ Mapear 9 campos obrigatórios:
     • Título do Treinamento
     • Categoria do Treinamento
     • Metodologia
     • Área de Conhecimento
     • Necessita Avaliação
     • Facilitador/Fornecedor
     • Data/Hora
     • Carga Horária
     • Procedimentos/Assuntos
  
  ✅ Ver progresso em tempo real (0/9 → 9/9 campos)
  
  ✅ Status visual: ✓ Completo / ⚠️ Incompleto
  
  ✅ Deletar templates com confirmação


📊 FLUXO COMPLETO
═══════════════════════════════════════════════════════════════════════════════

  CRIAR TEMPLATE
      ↓
  [Novo Template] → Preenche nome → [Criar]
      ↓
  Template aparece na lista com status ⚠️ Incompleto
      ↓
  UPLOAD EXCEL
      ↓
  [📁 Upload Excel] → Seleciona .xlsx → Salva
      ↓
  Arquivo armazenado, status continua ⚠️
      ↓
  MAPEAR CAMPOS
      ↓
  [🎯 Mapear Campos] → Interface visual
      ↓
  Clica células ou digita referências (A1, B2, etc)
      ↓
  Progresso atualiza: 1/9, 2/9, ... 9/9
      ↓
  [Salvar Mapeamento]
      ↓
  Status muda para ✓ Completo
      ↓
  USO
      ↓
  Ao gerar lista de presença, system oferece usar template
      ↓
  PDF gerado respeitando layout customizado

🎓 COMO USAR (PASSO A PASSO)
═══════════════════════════════════════════════════════════════════════════════

  1. ACESSAR
     └─ Procedimentos → Listas de Presença → [Templates] (novo botão)
  
  2. CRIAR
     └─ [Novo Template] → Nome → Descrição → [Criar]
  
  3. UPLOAD
     └─ [📁 Upload Excel] → Selecionar .xlsx → Enviar
  
  4. MAPEAR
     └─ [🎯 Mapear Campos] → Preencher 9 campos → [Salvar]
  
  5. USAR
     └─ Gerar lista de presença → PDF respeitando layout
