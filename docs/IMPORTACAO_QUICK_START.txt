🔄 MODOS DISPONÍVEIS:
====================

UPSERT (Padrão) ← RECOMENDADO
├─ Cria novos
├─ Atualiza existentes
└─ Mais seguro

CREATE (Apenas novos)
├─ Cria novos
├─ Ignora existentes
└─ Mais conservador

DRY-RUN (Teste)
├─ Simula operação
├─ NÃO salva nada
└─ Teste antes de fazer de verdade
