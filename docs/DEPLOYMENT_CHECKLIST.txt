## 🆘 TROUBLESHOOTING RÁPIDO

### Problema: "ModuleNotFoundError: No module named '${REDIS_URL}'"

☐ Clique em Variables  
☐ Procure por CELERY_BROKER_URL  
☐ Se começa com `${`, está errado  
☐ Cole a URL REAL do Redis (redis://default:PASSWORD@...)  
☐ Salve e faça novo deploy  

### Problema: Build falha com erro de syntax

☐ Verifique se você tem os arquivos:
  - [ ] Dockerfile.beat (criado)
  - [ ] entrypoint-beat.py (criado)
  
☐ Verifique se estão na raiz do projeto  
☐ Faça commit e push no GitHub  
☐ Force redeploy no Railway  

### Problema: Tarefas não aparecem em /admin/django_celery_beat/

☐ Confirme que Celery Beat iniciou ("Entering tick loop")  
☐ Confirme que DATABASE_URL está correto  
☐ Acesse admin do web-app (não do celery-beat)  
☐ Verifique se há Celery Workers rodando
