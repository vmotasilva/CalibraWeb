1️⃣  MODELOS DE DADOS (2 novos)
   ✅ SolicitacaoValidacaoMatriz
      - Rastreia solicitações de validação
      - Status: pendente → validada/rejeitada
      - Auditoria: quem pediu, quem vai validar, quando
      
   ✅ HistoricoValidacaoMassa
      - Registra execução de validações
      - Salva: validador, timestamp, contagem, motivo
      - Permanente e não editável

2️⃣  VIEWS (4 endpoints)
   ✅ solicitar_validacao_view()
      - Formulário para solicitar validação
      - URL: /matrizes/{id}/solicitar-validacao/
      - Cria SolicitacaoValidacaoMatriz com status=pendente
      
   ✅ validacoes_pendentes_view()
      - Dashboard para validador
      - URL: /validacoes/pendentes/
      - Mostra apenas solicitações dele
      
   ✅ validar_matriz_view()
      - Tela de revisão completa
      - URL: /validacoes/{id}/validar/
      - Mostra todas as avaliações agrupadas
      - Escolher: Aprovar ou Rejeitar
      
   ✅ validacao_rapida_view()
      - Validação sem solicitação prévia
      - URL: /matrizes/{id}/validacao-rapida/
      - Para casos simples/rápidos

3️⃣  TEMPLATES HTML (4 templates)
   ✅ solicitar_validacao.html
      - Formulário com estilo Bootstrap 5
      - Campo: Validador (dropdown)
      - Campo: Motivo (textarea)
      - Resumo da matriz
      
   ✅ validacoes_pendentes.html
      - Tabela com solicitações
      - Colunas: Matriz, Solicitante, Data, Motivo
      - Botão para validar cada uma
      
   ✅ validar_matriz.html
      - Tela completa de revisão
      - Resumo: Total, Colaboradores, Disciplinas
      - Avaliações por colaborador com farol badges
      - Opções: Validar/Rejeitar
      - Campo de comentário
      
   ✅ validacao_rapida.html
      - Formulário de confirmação simples
      - Mostra total de avaliações
      - Botão: Validar Agora

2. Status: PENDENTE
3. Salva timestamp
4. Direciona para validador

1. Acessar /procedures/validacoes/pendentes/
2. Ver lista de solicitações
3. Clicar "Validar"
4. Revisar todas as avaliações
5. Escolher: Aprovar ou Rejeitar
6. Adicionar comentário
7. Processar

↓

SISTEMA:
1. Atualiza status (VALIDADA/REJEITADA)
2. Cria HistoricoValidacaoMassa
3. Registra timestamp
4. Registra comentário
5. Salva permanentemente
