├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                   │
│  views.py → importar_procedimentos_view()                                        │
│  ├─ 🔐 @login_required (Autenticação)                                           │
│  ├─ 👤 can_manage_procedimentos() (Autorização)                                 │
│  ├─ 📂 Recebimento arquivo                                                      │
│  ├─ 🚀 Instancia ImportacaoProcedimentosService                                 │

│  └─ 📊 Retorna relatório                                                        │
│                                                                                   │
└─────────────────────────────────────────────────────────────────────────────────┘
                                      ↓
┌─────────────────────────────────────────────────────────────────────────────────┐
│                    🧠 SERVIÇO DE IMPORTAÇÃO (Business Logic)                     │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                   │
│  ImportacaoProcedimentosService                                                  │
│                                                                                   │
│  1. carregar_arquivo()                                                           │
│     ├─ Detecta formato (.xlsx, .xls, .csv)                                      │
│     ├─ Carrega com pandas                                                       │
│     └─ Valida não vazio                                                         │
│                                                                                   │
│  2. normalizar_colunas()                                                         │
│     ├─ Mapeamento flexível de nomes                                             │
│     ├─ 'Código' → 'codigo'                                                      │
│     ├─ 'NOME' → 'nome'                                                          │
│     └─ Valida obrigatórias presentes                                            │
│                                                                                   │
│  3. _validar_linha() [Para cada linha]                                          │
│     ├─ Código: 3-50 chars, único                                                │
│     ├─ Nome: obrigatório, até 200 chars                                         │
│     ├─ Datas: formato válido                                                    │
│     └─ Retorna erros específicos                                                │
│                                                                                   │
│  4. _parsear_data()                                                              │
│     ├─ DD/MM/YYYY     ✓                                                         │
│     ├─ YYYY-MM-DD     ✓                                                         │
│     ├─ DD-MM-YYYY     ✓                                                         │
│     └─ Múltiplos formatos suportados                                            │
│                                                                                   │
│  5. processar(modo)  [@transaction.atomic]                                       │
│     │                                                                            │
│     ├─ modo='upsert' (Padrão)                                                   │
│     │  ├─ if NOVO → CRIAR                                                      │
│     │  └─ if EXISTENTE → ATUALIZAR (apenas campos alterados)                   │
│     │                                                                            │
│     ├─ modo='create'                                                            │
│     │  ├─ if NOVO → CRIAR                                                      │
│     │  └─ if EXISTENTE → PULAR (sem erro)                                     │
│     │                                                                            │
│     └─ modo='dry_run'                                                           │
│        ├─ if NOVO → SIMULAR CRIAR                                              │
│        ├─ if EXISTENTE → SIMULAR ATUALIZAR                                    │
│        └─ NÃO SALVA NADA                                                       │
│                                                                                   │
│  6. gerar_relatorio_html()                                                      │
│     ├─ 📊 Resumo executivo                                                      │
│     ├─ ✅ Tabela de sucessos                                                    │
│     ├─ ❌ Tabela de erros                                                       │
│     └─ 🎨 Formatação Bootstrap                                                  │
│                                                                                   │
└─────────────────────────────────────────────────────────────────────────────────┘
                                      ↓

📈 FLUXO DE DADOS
═══════════════════════════════════════════════════════════════════════════════════

1. USUÁRIO ACESSA
   └─ GET /procedures/procedimentos/importar/
      └─ Renderiza formulário

2. USUÁRIO SELECIONA ARQUIVO
   └─ POST com arquivo_excel + modo
      └─ View recebe request

3. VIEW VALIDA
   ├─ @login_required ✓
   ├─ can_manage_procedimentos ✓
   └─ formulario.is_valid() ✓

4. SERVIÇO PROCESSA
   ├─ carregar_arquivo()
   │  └─ pandas.read_excel() / read_csv()
   │
   ├─ normalizar_colunas()
   │  └─ Mapeia nomes flexíveis
   │
   ├─ For cada linha:
   │  ├─ _validar_linha()
   │  │  └─ Se inválido → Registra erro
   │  │
   │  ├─ _preparar_dados_linha()
   │  │  └─ Limpa e normaliza
   │  │
   │  └─ processar(modo)
   │     ├─ UPSERT: get_or_create + update
   │     ├─ CREATE: get_or_create (ignora update)
   │     └─ DRY-RUN: Simula sem salvar
   │
   └─ Salva ou Simula (dentro de @transaction.atomic)

5. GERA RELATÓRIO
   └─ gerar_relatorio_html()
      └─ HTML com resumo + tabelas

6. RETORNA RESULTADO
   └─ render(template, contexto)
      └─ Exibe na página


🔄 MODOS DE OPERAÇÃO
═══════════════════════════════════════════════════════════════════════════════════

┌─ UPSERT (Padrão) ─────────────────────────────────────────────────────────┐
│                                                                             │
│  Entrada: Arquivo com POP.001 (novo), POP.002 (existente com novo rev)   │
│  Banco:   Tem POP.001 (rev 00)                                            │
│                                                                             │
│  Lógica:                                                                    │
│  1. POP.001:                                                               │
│     - Banco: codigo=POP.001, rev=00                                       │
│     - Arquivo: codigo=POP.001, rev=01                                     │
│     - Resultado: ATUALIZADO (rev: 00→01)                                  │
│                                                                             │
│  2. POP.002:                                                               │
│     - Banco: não existe                                                    │
│     - Arquivo: codigo=POP.002, rev=01                                     │
│     - Resultado: CRIADO                                                    │
│                                                                             │
│  Resumo: ✅ 1 criado, 🔄 1 atualizado                                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ CREATE (Apenas novos) ───────────────────────────────────────────────────┐
│                                                                             │
│  Entrada: Mesmo arquivo anterior                                           │
│  Banco:   Tem POP.001 (rev 00)                                            │
│                                                                             │
│  Lógica:                                                                    │
│  1. POP.001:                                                               │
│     - Já existe → PULA (sem erro, sem mudança)                            │
│                                                                             │
│  2. POP.002:                                                               │
│     - Não existe → CRIA                                                    │
│                                                                             │
│  Resumo: ✅ 1 criado, ⏭️ 1 pulado                                           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ DRY-RUN (Teste/Simulação) ──────────────────────────────────────────────┐
│                                                                             │
│  Entrada: Mesmo arquivo anterior                                           │
│  Banco:   Tem POP.001 (rev 00)                                            │
│                                                                             │
│  Lógica:                                                                    │
│  1. Valida dados ✓                                                          │
│  2. Simula operações (sem salvar)                                          │
│  3. Mostra o que SERIA feito                                              │
│  4. Banco fica INTACTO                                                     │
│                                                                             │
│  Resumo: "Seria criado 1, atualizado 1" (SEM SALVAR NADA)                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘


✅ VALIDAÇÕES AUTOMÁTICAS
═══════════════════════════════════════════════════════════════════════════════════

┌─ Validação de Arquivo ─────────────────────────────────────────────────────┐
│ ✓ Formato válido (.xlsx, .xls, .csv)                                       │
│ ✓ Arquivo não vazio                                                        │
│ ✓ Pode ser lido (não corrompido)                                          │
└────────────────────────────────────────────────────────────────────────────┘

┌─ Validação de Estrutura ───────────────────────────────────────────────────┐
│ ✓ Colunas obrigatórias presentes (codigo, nome)                           │
│ ✓ Mapeamento de nomes funciona                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ Validação de Dados (por linha) ───────────────────────────────────────────┐
│ ✓ Código: 3-50 caracteres                                                  │
│ ✓ Código: Único no banco (sem duplicatas)                                 │
│ ✓ Nome: Presente (não vazio)                                              │
│ ✓ Nome: Até 200 caracteres                                                │
│ ✓ Datas: Formato válido (múltiplos suportados)                            │
│ ✓ Sem duplicatas na mesma importação                                      │
└────────────────────────────────────────────────────────────────────────────┘

┌─ Transação ────────────────────────────────────────────────────────────────┐
│ ✓ @transaction.atomic                                                      │
│ ✓ Se erro: Rollback automático                                            │
│ ✓ Banco: Sempre consistente                                               │
│ ✓ Nada parcial (tudo ou nada)                                            │
└────────────────────────────────────────────────────────────────────────────┘
