## 🎯 Fluxo de Uso Rápido

### Criar e Usar Template (5 passos)

```
1. ACESSAR
   Listas de Presença → Clique "Templates"
   
2. CRIAR
   Clique "[Novo Template]"
   Preencha nome + descrição
   Clique "Criar"
   
3. UPLOAD
   Clique "[📁 Upload Excel]"
   Selecione arquivo .xlsx
   
4. MAPEAR
   Clique "[🎯 Mapear Campos]"
   Mapeie os 9 campos obrigatórios
   Clique "Salvar"
   
5. USAR
   Gere lista de presença
   Sistema usa template para PDF customizado
```
